## File a flight plan

The **Air Canada** container in the activity bar holds three views:

**Session** — live readout of the current coding session: status and time remaining, the route track, block time and callsign (your git branch). Title-bar buttons: ▶ Board, ⏸ Pause, ↻ Reset.

**Flight Plan** — a task checklist.

- **+** adds a task; click a task to rename it.
- Tick the checkbox when it has landed; landed tasks drop to the bottom.
- The badge on the activity-bar icon shows how many are still open.
- **Clear Landed Tasks** removes finished ones; **Clear Flight Plan** empties it.

Tasks are stored per workspace (per folder you have open), so each project keeps its own plan. With no folder open they're stored globally.

**Meetings** — manual reminders, no calendar account. Add a meeting with a time like `14:30` or `in 20`; five minutes before it starts a plane flies across a panel towing the meeting card, with Join / Snooze buttons. Use **Preview the Fly-by** to see it now.
