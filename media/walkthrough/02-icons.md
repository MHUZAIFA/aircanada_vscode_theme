## Aviation icons

Two optional icon sets ship with the theme:

**Product icons — "Air Canada Aviation"**
Workbench glyphs become aviation symbols: Explorer is a luggage tag, Search a radar sweep, Source Control an air-route network, Run & Debug an airliner, Extensions a cockpit gauge, Settings a turbine, Remote a control tower, the Terminal a runway, and Notifications the fasten-seatbelt sign.

**File icons — "Air Canada Aviation (Boarding Pass)"**
Every file is a boarding pass with an airline-style code (`TS`, `PY`, `MD`…) and a stub coloured by language. Folders are hangars; the workspace root is a control tower.

Both are independent of the colour theme and can be turned on or off at any time via **Preferences: Product Icon Theme** and **Preferences: File Icon Theme**.
