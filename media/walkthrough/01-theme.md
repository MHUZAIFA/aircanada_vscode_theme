## Select your aircraft

| Theme | Cabin |
| --- | --- |
| **Air Canada Flight Deck** | Night cockpit — near-black, Rondelle-red status bar |
| **Air Canada Signature Light** | White upper fuselage, black status bar |
| **Air Canada Rouge** | Burgundy base, bright Rouge red accents |

Syntax colours follow the EFIS grammar pilots read every day: **magenta** FMS route → keywords, **cyan** data → strings, **green** engaged → functions, **amber** caution → numbers, **red** warning → errors.
